DynoSim6
DynoSim6 is a real-time 3D engine simulation tool built to visualize and analyze engine mechanics, fluid flow, and performance dynamics across 2-stroke and 4-stroke engine layouts.

What’s New in This Version
Startup & Idle Fix: Re-tuned starter torque and idle air control logic so engines start reliably and hold a stable idle without instantly stalling out.

Refined 2-Stroke Exhaust Alignment: Corrected expansion chamber geometry and mounting points to align properly with 2-stroke exhaust port locations.

Expanded Smoke & Particle Effects: Dynamic exhaust rendering tailored to engine conditions—including cold-start condensation, rich throttle blips, and 2-stroke oil burn.

Upgraded Valvetrain Mechanics: HD cam lobes, spring compression cycles, and valve lift mechanics rendered in real-time.

Enhanced Forced Induction Models: Redesigned turbocharger housings, spinning turbine assemblies, wastegate flutters, and supercharger drives.

Audio Engine Refresh: Improved real-time sound synthesis matching exact firing orders, valve noise, supercharger whines, and exhaust notes.

Key Features
Engine Layouts: Full support for single-cylinder, inline, V-type, boxer, radial, and rotary engines.

Cutaway & Inspection Views: Interactive 360-degree camera with internal component transparency modes.

Live Instrumentation: Dynamic RPM gauges, manifold pressure/boost monitors, oil pressure, and exhaust gas temperatures.

Forced Induction: Toggle between Naturally Aspirated (NA), Turbocharged, and Supercharged setups.

Getting Started
Select an engine template from the main gallery (2-Stroke or 4-Stroke).

Set up intake, exhaust, and forced induction options in the configuration menu.

Hit Start to crank the engine and establish idle.

Use the throttle control to test dynamic rev response, particle behavior, and procedural audio.
